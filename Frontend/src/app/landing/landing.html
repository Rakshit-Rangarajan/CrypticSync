Our Approach

CrypticSync was designed with a "Security-First" and "User-Centric" philosophy. Here is how we tackled the project:

  • Scalable Role Management: We implemented a hierarchical role system (SuperAdmin, Admin, CTO, Manager, Employee) that controls every UI element and API endpoint.
  • Reactive State: Leveraging Angular Signals allowed us to create a UI that feels alive, updating attendance logs and notifications in real-time.
  • Email-Based Onboarding: To eliminate insecure hardcoded passwords, we built a token-based invitation system integrated with SMTP (Resend/Ethereal).
  • Robust Reporting: We built complex SQL queries to calculate overtime, lunch breaks, and partial attendance automatically.

Assumptions Made

  • Work hours are 9 hours/day (Mon-Fri).
  • Lunch break is 1 hour (included in 9h).
  • Attendance before 9 AM is early; after 9 AM is late.
  • SMTP server is available via environment variables.
